Overview

A definition is written in YAML. It describes a picture made of shapes, plus zooms: smaller copies of the whole picture placed inside itself. Each copy contains its own copies, and so on, which makes a fractal.

A definition has these parts. Only scene is required.

variables:  # named numbers to use in expressions
frame:      # the border drawn around the picture
view:       # picture size and coordinates
seed:       # colour of the smallest copies
scene:      # the shapes and zooms, in drawing order

Indentation matters in YAML. Lists use - at the start of each item. Text after # is a comment. Colours are any CSS colour, such as red or "#336699" (put quotes around colours that start with #, or YAML treats them as comments).

Any mistake is shown in red under the buttons, and nothing is drawn until it is fixed.

View

The view sets the shape of the picture, how many pixels it has, and its coordinates.

view:
  aspect: 4/3          # width divided by height
  resolution:
    height: 1200       # in pixels
  coordinates:
    x: [-4, 4]         # left edge, right edge
    y: [-3, 3]         # bottom edge, top edge
  • aspect is the width divided by the height. The default is 1 (square).
  • resolution may give width, height, or both. A missing one is worked out from the aspect. If both are given, they set the aspect. Without a resolution the picture is 1200 pixels high.
  • coordinates sets the numbers used to place things. x goes from left to right, and y goes from bottom to top, as in maths. Ranges can also be written { from: -4, to: 4 }. The default is -100 to 100 on both axes.

Frame

The frame only changes how the picture is shown on the page, not the picture itself. Sizes are in screen pixels.

frame:
  width: 12            # border thickness
  radius: 6            # rounded corners
  color: "#444"        # border colour
  wall: "#ddd"         # colour of the page around the frame
  background: "#fff"   # colour behind the picture
  padding: 12          # space between border and picture
  margin: 24           # space between frame and window edge

The background is not part of the picture. Downloaded images are transparent wherever nothing is drawn.

Scene

The scene is a list of items. Each item has a type, either rect or zoom. Items are drawn in order, so later items appear on top of earlier ones.

Any item may have a name, so other items can refer to its points. Names must be unique, cannot contain dots or spaces, and cannot be view.

Rectangles

- type: rect
  name: block
  centre: [0, 0]
  width: 2
  height: 1
  rotation: 30         # degrees, clockwise
  color: "#d97757"
  opacity: 0.8         # 0 is invisible, 1 is solid

Rectangles are filled with color (black by default) and have no outline. opacity defaults to 1.

Position and size

Rectangles and zooms are placed the same way. Give enough of these to fix exactly one rectangle:

  • centre: the middle point
  • topLeft, topRight, bottomLeft, bottomRight: corners
  • width and height
  • rotation: clockwise turn around the centre

Some combinations that work:

  • centre, width and height
  • one corner, width and height
  • two opposite corners, such as bottomLeft and topRight
  • two corners along one edge, plus the other size (the edge sets the rotation)
  • three corners (they set the size and rotation)

rotation can be added to most of these. Without it, the rectangle is not rotated unless the corners say otherwise. If the values are not enough, or they disagree, an error explains which item is wrong.

Rotation can be written in several ways:

rotation: 30              # degrees
rotation: 30deg           # degrees
rotation: pi/6 rad        # radians
rotation: { radians: 0.5 }
rotation: { degrees: 30 }

Points

A point can be written as a pair, an object, or a reference to another item.

centre: [1, 2]
centre: { x: 1, y: 2 }
centre: block.topRight    # a point of the item named block
centre: view.centre       # a point of the whole view

References use name.part, where the part is centre, top, bottom, left, right (edge middles) or a corner: topLeft, topRight, bottomLeft, bottomRight. Points follow the item's rotation. Items can refer to items defined later, as long as they do not refer to each other in a loop.

Zooms

A zoom is a rectangle that holds a copy of the whole view: everything in the scene, including the zooms themselves. The top left of the view lands on the zoom's top left corner, and so on. 

- type: zoom
  centre: [0.5, 0.5]
  scale: 0.5          # half the size of the view
  rotation: 15
  • Zooms are placed like rectangles, but have no colour.
  • scale gives the size as a fraction of the view. It cannot be used together with width or height.
  • If only width or height is given, the other comes from the view's aspect, so the copy is not stretched.
  • opacity fades the copy.

Alignment

align places a zoom by saying where a point of the full picture should end up in the copy. Each pair is [from, to]: from is a point in the full picture, and to is where that point's copy should go. 

- type: rect
  name: stem
  bottomLeft: [-0.11, -1]
  topRight: [-0.09, -0.7]
- type: zoom
  scale: 0.86
  rotation: -2
  align: [stem.bottomLeft, stem.topLeft]

Here, the copy's version of the stem starts where the real stem ends, so the stem grows upwards. With one pair, also give scale, width or height (and optionally rotation).

With two pairs, the zoom's size and rotation are worked out too:

align:
  - [view.bottomLeft, stem.topLeft]
  - [view.bottomRight, stem.topRight]

Pairs can also be written { from: ..., to: ... }.

Seed

Copies inside copies get smaller and smaller. When they become too small to see, they are drawn as a plain rectangle in the seed colour instead. The seed is transparent by default. 

seed: "#111827"

seed:
  color: "#111827"
  opacity: 0.9

Expressions

Anywhere a number is expected, you can write a calculation instead.

aspect: 2/sqrt(3)
width: 1/phi
x: [-4/3, 4/3]
rotation: 360/5
centre: [0, "root(3, 2)"]   # quote it if it contains a comma inside [ ]
Operators+ - * / ^ and brackets ( ). ^ is power. There is no hidden multiplication: write 2*pi, not 2pi.
Constantspi, e, phi (the golden ratio, about 1.618)
Rootssqrt(x), root(n, x) (the nth root of x)
Logslog(x) and ln(x) (both natural log), exp(x)
Trigonometrysin, cos, tan, asin, acos, atan, atan2(y, x), all in radians
Otherabs(x)

-2^2 is -4, because the power is worked out first. Use brackets to make things clear, such as (-2)^2.

Variables

Variables give a name to a number, so it can be used in expressions.

variables:
  - name: s
    value: 1/sqrt(2)
  - name: gap
    value: s/10

scene:
  - type: zoom
    centre: [0, gap]
    scale: s

Names start with a letter or _, and may contain letters, digits and _. They cannot be the same as a constant or function, such as pi or sin. Variables can use each other in any order, as long as they do not depend on each other in a loop.

View values

Expressions can also use these values from the view:

view.left, view.rightx of the left and right edges
view.bottom, view.topy of the bottom and top edges
view.width, view.heightsize of the view in coordinates
view.centre.x, view.centre.ymiddle of the view
view.aspectwidth divided by height
view.pixels.width, view.pixels.heightsize of the picture in pixels
view.pixel.width, view.pixel.heightsize of one pixel in coordinates
view:
  aspect: 3/2
  coordinates:
    x: [-view.aspect, view.aspect]
    y: [-1, 1]

A view value cannot be used to define itself. For example, the x range can use view.aspect but not view.width.

Note the difference between view.centre, which is a point (used as centre: view.centre), and view.centre.x, which is a number (used in expressions).
